# Author Identification using Machine Learning

## Overview
This project focuses on identifying the author of a given text using machine learning techniques.

## Problem Statement
Given a set of text samples from different authors, the goal is to build a model that can correctly classify the author of an unknown text.

## Approach
- Text preprocessing
- Feature extraction
- Machine learning classification

## Tools
- Python
- Scikit-learn
- NLP techniques

## Note
This project was implemented as a Jupyter Notebook focusing on experimentation and model building.
